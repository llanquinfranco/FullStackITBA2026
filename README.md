# Certificación Avanzada Full Stack Developer ITBA 2026

## Sprints

El programa y el desarrollo del proyecto se dividen en 8 etapas prácticas:

*   **Sprint 1 - Fundamentos del Frontend:** Estructura y semántica web con HTML, junto con diseño responsivo Mobile-First utilizando CSS y modelo de cajas.
*   **Sprint 2 - Interactividad con JavaScript:** Lógica de programación, manipulación dinámica del DOM, manejo de formato JSON y asincronía (Promises y async/await).
*   **Sprint 3 - Fundamentos del Backend con Node.js y Express:** Configuración del entorno de servidor, gestión de dependencias con NPM y creación de APIs mediante rutas y middlewares.
*   **Sprint 4 - Desarrollo Frontend con React:** Construcción de interfaces interactivas con componentes y JSX, manejando propiedades (props) y estados (useState).
*   **Sprint 5 - Conexión Full Stack y Ruteo:** Consumo de la API desde el cliente (fetch/useEffect) y navegación entre vistas (SPA) utilizando React Router DOM.
*   **Sprint 6 - Persistencia de Datos con MongoDB:** Introducción a bases de datos NoSQL, ejecución de operaciones CRUD y modelado de datos con Mongoose.
*   **Sprint 7 - Autenticación y Estado Global:** Seguridad de usuarios (Login/Registro) con JWT y bcrypt, y gestión del estado global de la aplicación usando Context API.
*   **Sprint 8 - Despliegue y Consolidación Final:** Organización del código con el patrón MVC, protección de rutas y despliegue del proyecto en la nube (MongoDB Atlas, Render y Vercel).
